# Лабораторная работа 3: Классы

## 1. Краткая теоретическая справка

### Значения по-умолчанию

Поля класса могут иметь значения по-умолчанию, то есть значения которые присваиваются
переменным-членам при создании нового экземпляра класса.
Если конструктор явно не изменит какое-либо поле, оно автоматически получит указанное значение.

Если все поля класса имеют значения по-умолчанию, то тело конструктора без параметров можно
заменить ключевым словом `= default`.

Пример класса с полями со значениями по-умолчанию и `default` конструктором:

```cpp
class Audio {
private:
    std::string title = "Unknown";
    std::string author = "Unknown";
    int year = 2026;

public:
    Audio() = default;
};
```

### Списки инициализации

Списки инициализации это специальный синтаксис конструктора
(записывается через двоеточие : перед телом функции), который инициализирует поля класса
до выполнения самого тела конструктора.
Это более эффективно, чем присваивание внутри, и это единственный способ инициализировать
переменные-члены не имеющие конструктора по-умолчанию, const-поля и ссылки.

```cpp
class Audio {
private:
    std::string title = "Unknown";
    std::string author = "Unknown";
    int year = 2026;

public:
    Audio(const std::string& t, const std::string& a)
        : title(t)    // Список инициализации
        , author(a)
    {  // Все уже проинициализировано значениями по-умолчанию
       // или в списке инициализации, поэтому тело пустое
    }
};
```

### Конструктор копирования

Конструктор копирования это особый конструктор, который вызывается
для создания нового объекта как точной копии уже существующего объекта
того же класса. Он принимает ссылку на объект своего же типа (обычно const).

```cpp
class Audio {
private:
    std::string title = "Unknown";
    std::string author = "Unknown";
    int year = 2026;

public:
    Audio(const Audio& other) {
        title = other.title;
        author = other.author;
        year = other.year;
    }
};
```

### Статические функции

Статические функции это функции класса, помеченные ключевым словом static.
Они принадлежат самому классу, а не его конкретным объектам.
Их можно вызывать без создания экземпляра класса, и они не имеют доступа к указателю this
(могут работать только со статическими полями класса).

Например, статическая функция может использоваться для создания объекта из
каких-либо данных (конвертация):

### Запись данных в файл

Для записи данных в файл используется класс ofstream из стандартной библиотеки std:

```cpp
#include <fstream>

int main()
{
    std::ofstream fout;

    fout.open("myfile.txt");

    if (fout.is_open()) {
        // Файл открыт, можно писать в него:
        fout << "Строка для записи в файл" << std::endl;
        fout << "Число: " << 67 << std::endl;
    }
    else {
        // Ошибка
    }

    // fout.close();
    // Закрывать файл не обязательно: он будет автоматически закрыт в деструкторе std::ofstream,
    // реализуя таким образом идиому RAII

    return 0;
}
```

При создании объекта или вызове метода `.open()`` вторым аргументом можно передать флаги, которые меняют поведение потока:

|Флаг|Описание|
|:--|:--|
|std::ios::out|Режим записи (включается автоматически для ofstream).|
|std::ios::app|Append (дозапись): Не стирает файл, а дописывает новые данные в самый конец.|
|std::ios::trunc|Truncate (очистка): Стирает всё содержимое старого файла (поведение по умолчанию).|
|std::ios::binary|Бинарный режим: Данные пишутся «как есть» в байтах, без форматирования перевода строк (\n -> \r\n на Windows).|

```cpp
// Добавить в файл данные, а не начинать запись с начала:
fout.open("myfile.txt", std::ios::app);
```
