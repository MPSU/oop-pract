## 1. Краткая теоретическая справка

### Виртуальные функции

Виртуальные функции (virtual) это функции члена класса, которые можно
переопределить в классах-наследниках. При использовании указателя или
ссылки на базовый класс, вызовется метод того объекта, на который он фактически указывает.

```cpp
#include <print>
#include <vector>

// Базовый класс для игровых юнитов
class Unit {
public:
    // Виртуальная функция
    virtual void attack() {
        std::println("Юнит атакует базовым уроном.");
    }
    virtual ~Unit() = default; // Виртуальный деструктор обязателен!
};

// Наследник: Воин
class Warrior : public Unit {
public:
    void attack() override { // override гарантирует переопределение
        std::println("Воин рубит мечом!");
    }
};

// Наследник: Маг
class Mage : public Unit {
public:
    void attack() override {
        std::println("Маг кастует огненный шар!");
    }
};

// Функция обновления игрового процесса,
// принимает ссылку на базовый класс Unit
void update(Unit& u) {
    u.attack();
    // Функция не знает, объект какого типа пришел на вход,
    // она просто вызывает виртуальный метод
}

int main() {
    Warrior wr;
    Mage mg;

    update(wr);
    update(mg);
}
// Вывод:
//   Воин рубит мечом!
//   Маг кастует огненный шар!
```

`virtual` -- заставляет программу выбирать метод во время работы (динамический полиморфизм), а не во время компиляции.

Виртуальный деструктор -- всегда пишите `virtual ~BaseClass() = default;` в базовом классе,
иначе при удалении наследника через указатель базового класса возникнет утечка памяти.


### Абстрактные классы в C++

Класс становится абстрактным, если в нем есть хотя бы одна чистая виртуальная функция (pure virtual function).
Создать объект такого класса напрямую нельзя -- он служит только фундаментом для наследников.
В играх это полезно для создания интерфейсов, например, для интерактивных объектов.

```cpp
// Абстрактный класс -- нельзя создать объект типа "InteractiveObject"
class InteractiveObject {
public:
    // Чистая виртуальная функция (= 0)
    virtual void interact() = 0; 
    virtual ~InteractiveObject() = default;
};

// Наследник: Сундук
class Chest : public InteractiveObject {
public:
    void interact() override {
        std::println("Сундук открылся. Вы получили легендарный меч!");
    }
};

// Наследник: Дверь
class Door : public InteractiveObject {
public:
    void interact() override {
        std::println("Дверь заперта, нужен ключ.");
    }
};
```

Чистая виртуальная функция -- это функция без реализации (без тела).

`= 0` -- делает функцию чистой виртуальной, а класс — абстрактным.
Наследники обязаны реализовать этот метод, иначе они тоже станут абстрактными.

Таким образом, наследования от абстрактного класса гарантирует наличие нужных
функций (одинакового интерфейса) у всех классов-наследников.

Применение абстрактных классов возможно через ссылки, указатели и умные указатели.

```cpp
#include <vector>
#include <print>

int main() {
    std::vector<InteractiveObject*> objects;

    objects.push_back(new Chest);
    objects.push_back(new Door);

    for (InteractiveObject* obj: objects) {
        obj->interact();
        // В цикле заранее не известно какой объект перед нами.
        // Но благодаря механизму виртуальных функций, каждый раз
        // будет запусаться нужный метод от того класса,
        // объектом которого он является на самом деле
    }

    // Объекты созданные через new надо удалить с помощью delete:
    for (InteractiveObject* obj: objects) {
        delete obj;
    }
}
```


### Чтение файлов типа JSON

[JSON](https://ru.wikipedia.org/wiki/JSON) - это текстовый формат файлов, который хранит данные в виде пар ключ-значение.

Например:

```json
{ "city": "Moscow", "year": 1147 }
```

Вложенные структуры в JSON записываются с помощью фигурных скобок:

```json
{
    "capital": { "city": "Moscow", "year": 1147 }
}
```

Массивы объектов записываются с помощью прямоугольных скобок:

```json
{
    "cities": [
        {"city": "Moscow", "year": 1147},
        {"city": "St.Petersburg", "year": 1703}
    ]
}
```

Записи об автомобилях в таком синтаксисе будут выглядеть примерно так:

```json
{
    "cars": [
        { "name": "Ford", "year": 2018, "power": 123 },
        { "name": "KIA", "year": 2023, "power": 115 },
    ]
}
```

Для чтения JSON мы будем искользовать библиотеку [nlohmann::json](https://github.com/nlohmann/json).
Для этого надо скачать файл [json.hpp](https://github.com/nlohmann/json/blob/develop/single_include/nlohmann/json.hpp)
и добавить его к проекту.

Пример получения данных из JSON-строки:

```cpp
// Текст в формате JSON:
//   { "city": "Moscow", "year": 1147 }
// \" нужны для экранирования кавычек, чтобы компилятор их не воспринял как конец строки
std::string jsonstr = "{ \"city\": \"Moscow\", \"year\": 1147 }";

// Создаем объект типа nlohmann::json и обрабатываем нашу строку
nlohmann::json j = nlohmann::json::parse(jsonstr);

std::string name;
int year;

// Считываем значение с ключом "city" в переменную name
j["city"].get_to(name);
// Считываем значение с ключом "year" в переменную year
j["year"].get_to(year);

// Теперь name = "Moscow", year = 1147
```

Для чтения данных из массива необходимо использовать цикл:

```cpp
std::string jsonarr = "{ \"cities\": [{ \"city\": \"Moscow\", \"year\": 1147 }, {\"city\": \"St.Petersburg\", \"year\": 1703}] }";

// Создаем объект типа nlohmann::json и обрабатываем нашу строку
nlohmann::json j = nlohmann::json::parse(jsonarr);

// В цикле проходим по всем элементам из "cities"
for (const auto& e: j["cities"]) {
    std::string name;
    int year;
    // И разбираем каждый элемент на составляющие
    e["city"].get_to(name);
    e["year"].get_to(year);

    // Используем полученные данные
    std::println("Город {} основан в {}", name, year);
}
```

Для чтения данных из файла используем `std::ifstream` и оператор `>>`:

```cpp
// Открываем файл 
std::ifstream fin("file.json");

nlohmann::json j;
fin >> j;

// ... обработка j
```


### Диалоговое окно выбора файлов

Для того чтобы пользователь выбрал какой файл открыть или сохранить,
в Qt используется класс [QFileDialog](https://doc.qt.io/qt-6/qfiledialog.html#details).

Например, чтобы отрыть диалоговое окно выбора файла для чтения надо вызвать
статический метод `getOpenFileName`:

```cpp
QString fileName = QFileDialog::getOpenFileName(
    this, 
    "Открыть изображение",
    "c:\\Users\\nobody", 
    "Изображения (*.png *.jpg)");
```

. Первый параметр -- родительский объект этого окна (чаще всего this);
. Второй параметр -- текст в заголовке окна;
. Третий параметр -- папка которая будет открыта при отображении окна;
. Четвертый параметр -- фильтр файлов, т.е. какие файлы показывать в выборе.

После вызова этого метода, получим в переменной `fileName` имя файла, который пользователь
выбрал. Если пользователь нажал `Отмена`, или закрыл окно, то `fileName` будет пустой строкой.
