### Основы наследования в C++

Наследование позволяет создавать новые классы (производные или дочерние), которые расширяют или модифицируют функциональность существующих (базовых) классов.
Наследование позволяет моделировать отношение "Является" (**IS-A**).
Например, **еда** является **предметом**, наследую его свойства (стоимость, вес, и пр.).

В C++ для реализации наследования необходимо при объявлении класса
через двоеточие указать название базового класса. Например:


```cpp
// Базовый класс "Существо"
class Entity {
private:
    float x, y;  // Координаты существа

public:
    void move(int dx, int dy);  // Перемещение
};

// Производный класс "Герой"
class Hero : public Entity {
//         ^^^^^^^^^^^^^^^  публичное наследование от класса Entity
private:
    std::string name;  // Имя героя

public:
    void sleep();  // Метод "лечь спать"
};
```

Использование:

```cpp
// Создаем героя (экземпляр класса "Hero")
Hero steave;

steave.move(4, 5);  // Вызов метода базового класса
steave.sleep();     // Вызов метода производного класса
```

### Спецификация наследования

При объявлении производного класса можно задать один из трех спецификаторов наследования:
public, protected, private.

Спецификатор определяет максимальный уровень доступа к унаследованным членам в производном классе.

| Модификатор в Base | public наследование | protected наследование | private наследование |
|---|---|---|---|
| private | Не наследуется | Не наследуется | Не наследуется |
| protected | protected | protected | private |
| public | public | protected | private |

Пример закрытого наследования:

```cpp
class Engine {
public:
    void start();
};

class Car : private Engine { 
    // start() стал private. Внешний код не может вызвать car.start();
};

int main()
{
    Car kiario;
    // kiario.start();  даст ошибку компиляции,
    // так как наследование закрытое и метод start стал закрытым.

    return 0;
}
```

### Конструкторы при наследовании

Объект производного класса состоит из двух частей: «подчасти» базового класса и собственных полей.
При создании экземпляра дочернего класса, конструктор родительского класса всегда
вызывается первым, до конструктора дочернего класса. Такми образом инициализация идет
сверху вниз по иерархии.

```cpp
class Base {
public:
    Base() {
        std::println("1. Base Constructor");
    }
};

class Derived : public Base {
public:
    Derived() {
        std::println("2. Derived Constructor");
    }
};
// Вывод при создании Derived obj:
// 1. Base Constructor
// 2. Derived Constructor
```

Если у базового класса нет конструктора по умолчанию, или если требуется вызвать
особый конструктор и передать ему параметры, то потомок должен
явно вызвать нужный конструктор в своем списке инициализации.

```cpp
class Parent {
    int id;

public:
    Parent(int p) : id(p) {}
};

class Child : public Parent {
    std::string name;

public:
    // Явный вызов конструктора Parent
    Child(int p, std::string n) : Parent(p), name(n)
    {  // Тело пустое
    }
};

int main()
{
    Child c(67, "Имя");
    // id = 67
    // name = "Имя"

    return 0;
}
```

### Полиморфизм и override в C++

Полиморфизм — это механизм ООП, который позволяет работать с разными типами объектов через единый интерфейс.
В C++ это реализуется через виртуальные функции.

Пример базового и дочернего классов с переопределением метода:

```cpp
class Entity {
public:
    virtual void info() const {
        std::cout << "Entity object" << std::endl;
    }
    virtual ~Base() = default;
};

class Hero : public Entity {
public:
    void info() const override {
        std::cout << "Hero object" << std::endl;
    }
};
```

Использование:

```cpp
void show(const Entity& en)
{
    // В качестве аргумента функции можно передать
    // любой класс, наследованный от Entity
    en.info();
}

int main()
{
    Hero steave;  // Создаем экземпляр класса Hero

    show(steave);  // И передаем его в функцию show()
}

// Вывод при запуске программы:
// Hero object
```

Ключевое слово `override` явно указывает, что метод переопределяет виртуальную функцию из базового класса.


### Наследование виджетов Qt

Наследование — это один из ключевых механизмов объектно-ориентированного программирования (ООП), который позволяет создавать новые классы на основе уже существующих, расширяя или изменяя их функциональность. В библиотеке Qt данный принцип используется для создания пользовательских виджетов, основанных на стандартных элементах управления.

Все элементы окна в Qt образуют иерархию, так что у каждого виджета есть родитель (*англ.* parent, не путать с родителем при наследовании в ООП) — виджет, на котором он расположен. Благодаря этому, управление ресурсами и отображением элементов интерфейса упрощается. Этот родитель должен быть обязательно передан в виджет при его создании (при вызове конструктора)ю
Поэтому у любого виджета (и любого наследованного от него класса) нет конструктора по-умолчанию,
но есть конструктор следующего вида:

```cpp
class QPushButton {
public:
    // Конструктор с указанием родительского объекта
    QPushButton(QWidget* parent = nullptr);
    ...
}
```

Поэтому при создании пользовательского виджета необходимо явно передавать указатель на родительский элемент в конструкторе.
Например, мы хотим создать свой класс кнопки `MyButton`, наделив его дополнительными
возможностями. Его конструктор будет выглядеть так:

Передача `parent` в конструктор базового класса выполняется через список инициализации, например:

```cpp
class MyButton : public QPushButton {  // Наследуем от QPushButton
public:
    MyButton(QWidget* parent)  // Обязательное указание родительского объекта (parent)
        : QPushButton(parent)  // Список инициализации с передачей parent в конструктор
                               // базового класса
    {
        // Тело, инициализация остальных свойств
    }
    ...
}
```

### Создание пользовательских виджетов в QtCreator

Для создания собственного виджета в QtCreator:
1. Создайте новый класс C++ и укажите базовый класс (например, `QPushButton`).
2. Подключите заголовочный файл `QPushButton` и добавьте макрос `Q_OBJECT` в объявление класса.
3. Определите конструктор с указателем на родительский объект.
4. Реализуйте дополнительную функциональность нового виджета.

Пример реализации пользовательского виджета `MyButton`:

```cpp
// MyButton.h

#ifndef MYBUTTON_H
#define MYBUTTON_H

#include <QPushButton>

class MyButton : public QPushButton {
    Q_OBJECT
public:
    explicit MyButton(QWidget* parent = nullptr);

    void awesome();  // Метод который хотим добавить к кнопке
};

#endif // MYBUTTON_H
```

```cpp
// MyButton.cpp
#include "MyButton.h"

MyButton::MyButton(QWidget* parent)
    : QPushButton(parent)
{
    // Сделаем кнопке красный цвет.
    // Для этого вызовем метод родительского класса,
    // и передадим ему стиль кнопки
    setStyleSheet("background-color: red; color: white;");
}

void MyButton::awesome()
{
    // Дополнительный метод, который расширяет функционал обычной кнопки
    // Здесь можно использовать любые методы, которые есть у QPushButton
}
```

Чтобы использовать пользовательский виджет в дизайнере интерфейса:
1. Добавьте виджет базовго класса (в нашем примере, QPushButton) в окно как обычно.
2. Щелкните по нему правой кнопкой мыши и выберите `Преобразовать в ...`.
3. Укажите имя производного класса и заголовочный файл.
4. Нажмите `Добавить`, затем `Преобразовать`.
5. В результате в иерархии элементов вашего окна родительский класс будет заменен на новый дочерний.

См. [Using Custom Widgets with Qt Widgets Designer](https://doc.qt.io/qt-6/designer-using-custom-widgets.html)

После этого к пользовательскому виджету можно обращаться как обычно через `ui->myName->...`.

### Подключение заголовочного файла в CMake

При возникновении ошибок компиляции, связанных с отсутствием заголовочного файла пользовательского класса, добавьте в `CMakeLists.txt` строку:
```cmake
target_include_directories(proj PUBLIC ${CMAKE_CURRENT_LIST_DIR})
```
где `proj` — имя *ВАШЕГО* проекта (указано в директиве `project(...)`).
