## 1. Краткая теоретическая справка

### Создание простейшего класса в C++

Класс в C++ объединяет данные (поля) и функции для работы с ними (методы). Описание класса принято делить на две части: заголовочный файл (.h) с объявлением структуры класса и файл реализации (.cpp) с кодом методов.

Пример объявления класса (файл audio.h):

```cpp
#ifndef AUDIO_H
#define AUDIO_H

#include <string>

class Audio {
public:
    std::string title;
    std::string author;
    int year;
};

#endif // AUDIO_H
```

Так как в классе Audio пока нет методов, то файл `audio.cpp` не создаем.


### Чтение CSV-данных с помощью std::ifstream

CSV-файл это простой текстовый файл, содержащий записи об объектах.
Каждая строка содержит значения разделенные точкой с запятой ; или запятой.
Пример содержимого:

```
Имя;Фамилия;Год рождения;Эпоха
Александр;Пушкин;1799;Золотой век
Михаил;Лермонтов;1814;Романтизм
Александр;Блок;1880;Серебряный век
```


Для работы с файловыми потоками используется библиотека `<fstream>`.
Чтение текстового файла CSV выполняется построчно с помощью `std::getline`,
после чего каждая строка разбивается на токены.

Пример чтения данных:

```cpp
// Добавим заголовочный файлы, которые понадобятся
#include <fstream>
#include <vector>

#include "audio.h"

// Вектор (динамический массив) в котором будем
// хранить записи о музыкальных композициях
std::vector<Audio> tracks;

// Объявляем файловый поток (переменную типа std::ifstream)
// из которого будем читать данные
std::ifstream file(filename);

// Всегда проверяем, открыт ли файл    
if (!file.is_open()) {
    // Файл не открылся, выведем ошибку в окно программы
}

std::string line;

// В цикле читаем файл построчно
while (std::getline(file, line)) {
    std::string title, author, yearStr;

    // line теперь содержит одну строку из файла.
    // Надо разбить ее на части по разделителю ';'
    // и записать в title, author, yearStr
    ....
    (делается самостоятельно)


    // Собираем объект Audio
    Audio a;
    a.title = title;
    a.author = author;
    // Применяем std::stoi для преобразования строки в число
    a.year = std::stoi(yearStr);

    // И, наконец, добавляем в массив произведений
    tracks.push_back(a);
}

// Не забываем закрыть файл после чтения
file.close();

// Теперь у нас есть целый массив tracks, в котором записаны
// данные из файла и мы можем дальше их обрабатывать.
```


### Разработка графического интерфейса в Qt Widgets

Интерфейс приложения в Qt Widgets базируется на классах окон (например, QMainWindow).
Элементы интерфейса создаются динамически (или через Qt Designer)
и размещаются внутри Layout-компоновщиков для автоматического управления размерами.
Взаимодействие элементов построено на механизме сигналов и слотов.

Для вывода текстовой информации используется виджет QTextBrowser,
поддерживающий как обычный текст, так и форматирование HTML.

Рассмотрим процесс создания проекта в QtCreator.

1) В начальном окне QtCreator (или в меню Файл) нажимаем кнопку 'Создать проект'
и в появившемся окне выбираем 'Приложение Qt Widgets'.

2) Затем надо указать название и размещение вашего будущего проекта.

   **Не используйте путь по умолчанию!** Создайте на диске D: свою папку и храните
   все проекты в ней.

3) На следующем шаге надо выбрать систему сборки -- оставим по-умолчанию CMake.

4) Далее необходимо выбрать имя класса главного окна и названия файлов
в которых он будет описан. Оставляем здесь значения по-умолчанию.

5) На пятом шаге необходимо выбрать комплект сборки
(набор компилятор + стандартная библиотека + библиотека Qt).
Здесь нужно выбрать комплект **Desktop MIET Qt 6.9.1**.

После завершения, мастер создаст для вас проект состоящий из 5 файлов:
- `CMakeLists.txt` -- описание и настройки проекта (для открытия проекта надо открыть именно этот файл).
- `main.cpp` -- файл содержащий точку входа в программу -- функцию main().
- `mainwindow.h` и `mainwindow.cpp` -- описание класса MainWindow, в котоорм реализуется вся логика работы программы.
- `mainwindow.ui` -- дизайн вашего окна MainWindow.

Откройте файл `mainwindow.ui`, QtCreator переключится в режим дизайнера. Слева будет панель
с виджетами (элементами окна), которые можно расположить на окне.
Справа будет дерево виджетов и панель свойств виджета.

Поэкспериментируйте с добавлением разных виджетов в дизайн.
У каждого виджета есть набор свойств, которые можно менять. Самое важное
свойство объекта -- `objectName`. `objectName` позволяет обратиться к
этому виджету из кода окна. Все `objectName` должны быть уникальны.

Файл `mainwindow.cpp` содержит в себе две функции.
Конструктор класса `MainWindow` -- это специальная функция которая запускается
при создании окна.

```cpp
MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    // ui -- User Interface
    // textBrowser -- objectName для текстового окна QTextBrowser
    // clear() -- функция, очищающая текстовое окно

    ui->textBrowser->clear();

    // Добавьте сюда код считывания данных из CSV-файла
}
```



И деструктор класса MainWindow -- специальная функция, запускающаяся при
закрытии окна.

```cpp
MainWindow::~MainWindow()
{
    delete ui;
}
```


### Обработка данных из CSV-файла и вывод на экран

После чтения данных из CSV-файла и записи их в вектор, с ними можно работать,
например сортировать. Для этого можно воспользоваться функцией std::sort.

```cpp
#include <algorithm>

std::sort(tracks.begin(), tracks.end(), [](const Audio& a, const Audio& b){
    return a.year > b.year;
});
```

У функции std::sort три параметра:
- Начало коллекции -- откуда начинать сортировку;
- Конец коллекции -- до какого элемента сортировать;
- И третий -- функция сравнения двух элементов массива (компилятор 
не знает как сравнить две аудиозаписи, он умеет сравнивать только
простые типы данных). В примере использована лямбда-функция, подробнее о них будет позже.


После того как данные отсортированы, можно вывести их в Text Browser, например так:

```cpp
ui->textBrowser->append("My text");  // Добавить строку к тексту уже имеющемуся в окне

ui->textBrowser->setText("Другой текст");  // Заменить весь текст в окне на новый

ui->textBrowser->clear();  // Очистить окно вывода текста

// Range-based for -- цикл по коллекции
for (const Audio& a: tracks) {
    ui->textBrowser->append(QString::fromStdString(a.title));
}
```

Range-based for позволяет пройтись по массиву данных и выполнить
действие с каждым элементом массива.

`QString::fromStdString()` -- функция позволяющая преобразовать
строку std::string в строку QString. Дело в том, что в Qt все виджеты
используют свою реализацию строк (QString) не совместимую со стандартными
строками C++ (std::string). Поэтому необходимо преобразование.

Обратное преобразование можно сделать так:

```cpp
QString a;
std::string b = a.toStdString();
```
