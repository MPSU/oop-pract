# Лабораторная работа 8: Шаблоны

## 1. Краткая теоретическая справка

Шаблоны -- это средство языка C++, позволяющее параметризовать функции или классы типами данных.
Вместо написания отдельного кода для `int`, `double` или пользовательских структур,
компилятору предоставляется шаблон (трафарет), по которому он сам генерирует
нужный код в момент компиляции. Этот процесс называется инстанцированием (instantiation).


### Шаблоны функций (Function Templates)

Шаблоны функций используются, когда один и тот же алгоритм должен применяться к разным типам данных.

Синтаксис:

```cpp
template<typename T>
T max_value(T a, T b)
{
    return (a > b) ? a : b;
}
```

- `template <...>` -- ключевое слово, открывающее объявление шаблона.
- `typename T` (или `class T`) -- параметр шаблона, обозначающий обобщенный тип.
  Внутри функции `T` используется как обычный тип.
- `T` -- название, может быть любым правильным идентификатором C++, например `Type`, или `T1`.

Вызов и инстанцирование:

Компилятор может выводить тип автоматически из аргументов функции или принимать его явно:

```cpp
int main()
{
    auto res1 = max_value(5, 10);            // Автоматический вывод: T -> int
    auto res2 = max_value(3.14, 2.71);       // Автоматический вывод: T -> double
    float res3 = max_value<float>(5, 2.3f);  // Явное указание типа, T -> float
}
```


### Шаблоны классов (Class Templates)

Шаблоны классов позволяют создавать обобщенные структуры данных (контейнеры),
такие как массивы, списки, стеки.

Синтаксис и реализация методов:

```cpp
template<typename T>
class Box {
private:
    T value;

public:
    Box(T val) : value(val) {}

    T getValue() const;
};

// Реализация метода вне тела класса требует повторения заголовка шаблона:
template <typename T>
T Box<T>::getValue() const
{
    return value;
}
```

Использование:

При создании объекта шаблона класса до C++17 требовалось обязательно указывать тип в угловых скобках.
Начиная с C++17 работает механизм CTAD (Class Template Argument Deduction --
автоматический вывод аргументов шаблона класса):

```cpp
Box<int> myIntBox(10);  // Явное указание (C++11 и старше)
Box myDoubleBox(5.5);   // Автоматический вывод типа double (C++17)
```

### Шаблоны с несколькими параметрами

Шаблоны в C++ не ограничиваются одним параметром `T`. Вы можете передавать произвольное
количество параметров через запятую в угловых скобках `template <...>`. Параметры могут
быть как разными типами данных, так и комбинацией типов и значений.

```cpp
template<typename T1, typename T2>
class Calculator {
    // Код класса...
};

Calculator<int, double> calc1;   // Создаст Calculator<int, double>
Calculator<float, float> calc2;  // Создаст Calculator<float, float>
```


### Нетиповые параметры шаблонов (Non-type Template Parameters)

Параметрами шаблона могут быть не только типы, но и значения
(например, целые числа, указатели или ссылки).
Самый частый пример -- задание размера статического массива.

```cpp
template<typename T, size_t Size>
class StaticArray {
private:
    T data[Size];  // Размер массива известен на этапе компиляции

public:
    size_t getSize() const {
        return Size;
    }
};

// Использование:
StaticArray<int, 10> myBuffer;
```

*Примечание:* size_t -- это специальный встроенный тип данных в C и C++, который
представляет собой беззнаковый целочисленный тип (unsigned integer). Он используется
для задания размеров массивов, векторов и т.п.


### Параметры по умолчанию (Default Template Arguments)

Как и у обычных функций, у параметров шаблонов могут быть значения (типы)
по умолчанию. Если при создании объекта тип не указан явно (и компилятор не может его вывести),
будет использовано значение по-умолчанию.

```cpp
template<unsigned Num = 3>
class Polygon {
    // Код класса многоуголник...
};

Polygon<5> p1;  // Создаст пятиугольник
Polygon p2;     // Создаст треугольник
```

*Примечание:* Параметры по умолчанию должны идти в самом конце списка параметров шаблона.


### Специализация шаблонов (Template Specialization)

Иногда для определенного типа данных стандартный алгоритм шаблона не подходит
или неэффективен (например, сравнение строк `char*` требует `strcmp`, а не оператора >).
Для этого используется специализация.

- Полная специализация -- заменяет шаблон целиком для конкретного типа.
- Частичная специализация (только для классов) -- специализирует шаблон лишь для части
  параметров или для определенного подмножества типов (например, для указателей `T*`).

Пример полной специализации функции:

```cpp
// Базовый шаблон
template<typename T>
void print(T val)
{
    std::cout << "Общий шаблон: " << val << "\n";
}

// Полная специализация для типа bool
template<>
void print<bool>(bool val)
{
    std::cout << "Специализация для bool: " << (val ? "true" : "false") << "\n";
}
```


### Важные особенности и ограничения шаблонов

1. Раздельная компиляция: код шаблона не является готовым скомпилированным кодом.
   Компилятору нужно видеть всё определение шаблона (включая реализацию методов)
   в месте его инстанцирования. Поэтому шаблоны обычно полностью описывают
   в заголовочных файлах (`.h` / `.hpp`), а не разделяют на `.h` и `.cpp`.
2. Увеличение размера бинарного файла (Code Bloat): для каждого нового типа,
   с которым вызывается шаблон, компилятор генерирует отдельную копию кода.
   Это может приводить к раздуванию размера программы.
3. Строгая типизация: если внутри шаблона используется операция (например, a + b или a > b),
   то тип `T`, переданный в шаблон, обязан поддерживать эти операторы, иначе произойдет ошибка компиляции.
4. Сложность отладки: ошибки компиляции шаблонов часто бывают длинными и трудными для чтения,
   так как компилятор выводит всю цепочку инстанцирования.
